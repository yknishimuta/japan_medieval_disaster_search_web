# 『日本中世気象災害史年表稿』詳細検索（Web版）

藤木久志 編『日本中世気象災害史年表稿』（高志書院）の公開CSVデータを、**ブラウザから検索・閲覧・CSV出力するための非公式Webアプリ**です。

Web版の利用にはRuby／Rails・MySQL・Docker・Pythonのインストールも必要ありません。検索処理はブラウザ内で行われます。

- **データ出典**：藤木久志 編『日本中世気象災害史年表稿』（高志書院、2007年）。データ公開：東京大学史料編纂所。
- **公式データセット**：<https://lab.hi.u-tokyo.ac.jp/datasets/saigai>
- **公式ビューア・凡例**：<https://www.hi.u-tokyo.ac.jp/collection/digitalgallery/disaster_events/about>
- **DOI**：<https://doi.org/10.57459/hi.dg.disaster_events>
- **原データのライセンス**：[CC BY 4.0（表示 4.0 国際）](https://creativecommons.org/licenses/by/4.0/deed.ja)

> **ご注意**：本アプリは東京大学史料編纂所の公式サービスではありません。配布物には、提供された旧Railsアプリに収録されていたCSV（13,578件、9列）を使用しています。公開元のCSVの最新状態との同一性は保証しません。

## 使い方

`index.html` を直接ブラウザで開くと、ブラウザのセキュリティ制限によりCSVの自動読み込みが失敗する場合があります。その場合は、画面上のファイル選択欄からCSVファイルを指定してください。

「検索条件」に語句や年代などを入力し、**「検索する」**を押してください。

- 複数の検索欄を指定すると、それらを**すべて満たす**記事が表示されます。
- 結果は年代順に並び、1ページあたり20・50・100件を選べます。
- **「結果をCSVで保存」**を押すと、現在のページだけでなく、**検索に一致した全件**を保存できます。
- 「条件をクリア」で検索条件を初期状態に戻せます。

## 検索機能

| 検索項目 | 指定方法・動作 | 入力例 |
| --- | --- | --- |
| 天変地異などの記事 | 記事本文の語句を部分一致検索。空白区切りで複数指定可能 | `雨 雷` |
| キーワードのOR／AND | 「いずれかを含む（OR）」または「すべてを含む（AND）」を選択 | `雨 雷` + AND |
| 西暦・開始年／終了年 | グレゴリオ暦の年を、指定した両端を含めて絞り込み | `1180` ～ `1333` |
| 和暦 | 年号・年・月・日・閏月で検索。数字は全角やゼロ埋めにも対応 | `延喜2年6月17日` |
| 地域 | 部分一致検索 | `京都` |
| 原出典 | 部分一致。チェックすると完全一致 | `日本紀略` |
| 掲載書誌 | 部分一致。チェックすると完全一致 | `大日本史料` |
| 表示順 | 年代の古い順／新しい順 | 古い順 |

たとえば、本文に「雨」と「雷」の両方を含む記事を1200～1400年に限定する場合、キーワードに `雨 雷` と入力して **AND** を選び、開始年 `1200`・終了年 `1400` を指定します。
